# Digital Communication Systems 1 Simulator

An interactive single-page web app for experimenting with Digital Communication Systems 1 course concepts. Everything runs in the browser - no installation needed.

**Live demo:** https://mm9036922-gif.github.io/dcs1-simulator/

## What it does

- **Line coding:** visualize NRZ-L, RZ and Manchester encoding of a bit stream
- **Encryption:** optionally apply an XOR key cipher or a Caesar bit-shift cipher in the signal chain
- **Modulation & demodulation:** pass the signal through a digital modulator/demodulator stage
- **BER analysis:** plot bit-error rate against SNR on an interactive chart

## How to use

Open `index.html` in any modern browser, or visit the live demo link above. Enter a message, pick your line coding, encryption and channel settings, and watch each stage of the communication chain visualized.

Built as a course project for Digital Communication Systems 1.
